# farfarfun

![org-stars](https://img.shields.io/github/stars/farfarfun/farfarfun?style=flat-square) ![org-forks](https://img.shields.io/github/forks/farfarfun/farfarfun?style=flat-square) ![org-issues](https://img.shields.io/github/issues/farfarfun/farfarfun?style=flat-square) ![license](https://img.shields.io/badge/license-MIT-lightgrey?style=flat-square)

这是 [farfarfun](https://github.com/farfarfun) 组织的 profile 仓库，内容会展示在组织主页上；同时它也发布了一个同名的 PyPI 占位包 `farfarfun`，用于保留组织名对应的包名，本身不含任何功能代码。

一个以 "好玩、实验、学习" 为核心的组织，汇集个人项目、练手仓库与技术笔记。我们的目标是用轻量的项目探索新技术、分享学习成果，并通过开源的方式积累与他人协作的经验。

> 本组织的仓库会根据需要同步到国内镜像（如 Gitee）。

## 安装

```bash
pip install farfarfun
```

## 快速开始

`farfarfun` 包本身只是一个占位包（空的 `__init__.py`），导入即可验证安装成功：

```python
import farfarfun
```

## 我们做什么

- 开发小型工具、脚手架与 Demo，用于快速验证想法。
- 撰写实验性技术笔记与教程，记录学习过程和心得。
- 收集模板与实践样例，帮助快速上手常见开发任务。

## 项目一览

前往 [farfarfun 组织主页](https://github.com/farfarfun?tab=repositories) 浏览全部仓库。

## 浏览其他仓库

1. 在 Repositories 页面浏览仓库列表，选择感兴趣的项目。
2. 进入对应仓库阅读 README，按照其中的安装与运行说明操作。

示例命令：

```bash
git clone https://github.com/farfarfun/<repo-name>.git
cd <repo-name>
# 按项目 README 中的说明运行
```

## 如何贡献

我们欢迎各种形式的贡献：Issue、PR、建议、报告 Bug 或提交文档改进。推荐流程：

1. 在目标仓库创建 Issue 描述问题或建议。
2. Fork 仓库并创建分支（feature/xxx 或 fix/xxx）。
3. 提交改动并发起 Pull Request，说明变更目的与测试方式。

对于重大改动，请先在 Issue 中与维护者沟通以达成共识。
